# 🎓 Student Data Organizer

> A simple and structured student information management project
> designed to organize student details and subjects in one place.

------------------------------------------------------------------------

## 📌 About the Project

**Student Data Organizer** is a Python-based project that provides a
simple way to manage student information.

It keeps student records organized and allows the user to perform
essential data-management operations such as adding, viewing, updating,
and deleting student records.

The project also collects and displays the subjects associated with the
students.

------------------------------------------------------------------------

## ✨ Key Features

  -----------------------------------------------------------------------
  Feature                             Description
  ----------------------------------- -----------------------------------
  👤 Student Management               Keeps student information organized
                                      in individual records

  ➕ Add Student                      Adds a new student with personal
                                      and academic details

  👀 View Students                    Displays the available student
                                      records

  ✏️ Update Student                   Updates selected student
                                      information

  🗑️ Delete Student                   Removes a student record

  📚 Subject Management               Keeps track of subjects associated

  -----------------------------------------------------------------------

------------------------------------------------------------------------

## 🗂️ Information Managed

Each student record contains:

-   🆔 **Student ID**
-   👤 **Name**
-   🎂 **Age**
-   🎓 **Grade**
-   📅 **Date of Birth**
-   📚 **Subjects**

The information is arranged so that related details stay together and
can be managed as a single student record.

------------------------------------------------------------------------

## 🧠 Python Concepts Demonstrated

This project focuses on practical use of fundamental Python data
structures:

-   📋 **List** --- stores the collection of students
-   📖 **Dictionary** --- organizes information belonging to each
    student
-   🔢 **Tuple** --- groups the Student ID and Date of Birth
-   📚 **Set** --- stores subjects and helps maintain unique subject
    values

------------------------------------------------------------------------

## 🔄 Main Operations

### ➕ Add

Creates a new student record containing personal, academic, and subject
information.

### 👀 Display

Shows the student records currently maintained by the organizer.

### ✏️ Update

Allows selected student information to be changed.

### 🗑️ Delete

Removes a selected student record from the organizer.

### 📚 Display Subjects

Collects subjects from the student records and presents the subjects
available across the organizer.

## 🎯 Purpose

The main purpose of this project is to demonstrate how basic Python data
structures can be combined to create a practical student information
organizer.

sets** into a small, understandable data-management application.
