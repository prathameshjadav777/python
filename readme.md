# Pattern Generator and Number Analyzer

A simple Python console application that combines two beginner-friendly programs:

- Generate a star pattern.
- Analyze a range of numbers as even or odd and calculate their total sum.

## Features

### 1. Pattern Generator

The program asks for the number of rows and generates an increasing star pattern.

Example:

```text
*
**
***
****
*****
```

### 2. Number Analyzer

The program asks for a starting and ending number.

For every number in the range, it:

- Checks whether the number is even or odd.
- Displays the result.
- Adds the number to the total.
- Displays the sum of the complete range.

### 3. Interactive Menu

The program provides three choices:

```text
1. Generate a Pattern
2. Analyze a Range of Numbers
3. Exit
```

The menu continues to run until the user selects the exit option. The program's menu and core operations are implemented in the uploaded Python file.

## Requirements

- Python 3.x
- No external libraries are required.

## How to Run

1. Download or clone this repository.

2. Open the project folder in a terminal.

3. Run the Python file:

```bash
python "logic box(2).py"
```
