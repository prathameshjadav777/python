# 🧑‍💻 Interactive Personal Data Collector

> 🐍 A beginner-friendly Python project that collects personal information, displays its **data type and object ID**, and calculates an approximate birth year.

---

## 📌 About The Project

**Interactive Personal Data Collector** is a simple Python fundamentals project.

The program asks the user to enter:

* 👤 Name
* 🎂 Age
* 📏 Height in meters
* 🔢 Favorite number

It then displays the entered information along with its Python **data type** and **object ID**, followed by an approximate birth-year calculation.

---

## ✨ Features

* 👤 Collects user's name
* 🎂 Takes age as an integer
* 📏 Takes height as a floating-point number
* 🔢 Takes a favorite number
* 🔍 Displays the data type using `type()`
* 🆔 Displays the object identity using `id()`
* 📅 Calculates an approximate birth year
* 👋 Displays a goodbye message

## 🧠 Python Concepts Used

### `input()`

Used to take information from the user.

### `int()`

Converts input into an integer.

### `float()`

Converts input into a decimal number.

### `type()`

Shows the data type of a value.

### `id()`

Shows the identity of a Python object.

The program uses these concepts to collect and display the user's information.

---

## 📅 Birth Year Calculation

The program estimates the birth year using:

```python
birthyear = 2026 - age
```

⚠️ This is an approximate calculation because the program does not ask for the user's exact date of birth.
