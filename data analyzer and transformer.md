# 📊 Data Analyzer and Transformer

A simple **Python-based data analysis program** designed to perform common operations on a collection of numerical data through an easy-to-use menu-driven interface.

The project demonstrates several important Python concepts, including **built-in functions, recursion, lambda functions, filtering, sorting, and returning multiple values from functions**.

## ✨ Features

The program provides a collection of useful operations for working with numerical data:

* 📥 **Input Data** — Enter and store numerical data.
* 📊 **Data Summary** — View the total number of elements, minimum, maximum, sum, and average.
* 🔢 **Factorial Calculator** — Calculate the factorial of a number using recursion.
* 🔍 **Data Filtering** — Filter values based on a selected threshold using a lambda function.
* ↕️ **Data Sorting** — Arrange data in ascending or descending order.
* 📈 **Dataset Statistics** — Calculate and display important statistical values.
* 🚪 **Exit Option** — Safely exit the program.

---

## 🧠 Python Concepts Used

This project demonstrates several fundamental Python programming concepts:

### Built-in Functions

Functions such as `len()`, `min()`, `max()`, `sum()`, `map()`, and `sorted()` are used to process and analyze the data.

### Recursion

A recursive function is used to calculate the **factorial** of a number.

### Lambda Function

A lambda function is used with filtering to select values that meet a specified threshold.

### Filter Function

The `filter()` function helps identify values that satisfy the selected condition.

### Sorting

The program can organize the stored data in both **ascending and descending order**.

### Returning Multiple Values

The statistics function returns multiple calculated values together, including the minimum, maximum, total, and average.
